# 🧮 Calculator App

A sleek, fully functional calculator built with **HTML, CSS, and JavaScript**. Supports keyboard input and handles all basic arithmetic operations.

## 🔗 Live Demo
[Try it here](https://roshini15nivada.github.io/calculator-app)

---

## ✨ Features
- Addition, subtraction, multiplication, division
- Decimal support
- Delete last digit (⌫) and Clear All (AC)
- **Keyboard support** — type numbers and operators directly
- Expression preview shown above the result
- Error handling for invalid expressions
- Responsive, mobile-friendly design

## 🛠️ Built With
| Technology | Purpose |
|---|---|
| HTML5 | Calculator structure |
| CSS3 | Dark theme, grid layout, hover effects |
| JavaScript | Calculation logic, keyboard events |
| Google Fonts | Space Mono (monospace display font) |

## 📁 Project Structure
```
calculator-app/
├── index.html   # Layout with button grid
├── style.css    # Dark theme styles
├── script.js    # Logic: append, calculate, keyboard support
└── README.md
```

## 🚀 How to Run
1. Clone: `git clone https://github.com/roshini15nivada/calculator-app.git`
2. Open `index.html` in browser — no setup needed!
